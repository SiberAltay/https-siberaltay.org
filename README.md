# Altay Takımı — Landing Page

Siber Vatan projesi kapsamında Blue Team alanında uzmanlaşan **Altay Takımı**
için hazırlanmış, tamamen frontend bir landing page.

## Teknolojiler

- React + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion (`useScroll` / `useTransform` ile parallax ve scroll-bound reveal efektleri)

## Geliştirme

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Görseller

Tam ekran arkaplan görselleri ve takım logosu henüz eklenmedi. Nereye
ekleneceğine dair notlar için bkz. `public/GORSELLER.md`.
